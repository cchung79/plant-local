# 우리 집 식물

A small offline-first web app for tracking houseplant watering and fertilizing on a phone.

- All plant data stays in the browser on each phone (localStorage); move it between phones with the backup file (설정 → 내보내기/가져오기).
- Optional online features run only when a button is pressed, with keys the user enters on the phone:
  Pl@ntNet (identification), Wikidata/Wikipedia, Perenual, Kindwise plant.health, Claude.
- No plant data or keys are stored in this repository.

Plant identification by [Pl@ntNet](https://plantnet.org).
